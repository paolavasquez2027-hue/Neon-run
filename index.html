NEONRUN3D

Salta entre plataformas flotantes, esquiva los obstáculos y recoge todas las monedas.

RÉCORD 0 —

Teclado: WASD / flechas para moverte, ESPACIO para saltar, P para pausar.

INSTRUCCIONES

🎮 Teclado

  • W A S D o flechas — mover al personaje
  • ESPACIO — saltar (dos veces = doble salto)
  • D o SHIFT — avanzar a toda velocidad
  • W — acelerar el avance
  • S — frenar y retroceder
  • P o ESC — pausa · M — sonido · R — reiniciar

📱 Táctil

  • ◀ ▶ — moverte de lado
  • ▲ — saltar
  • Desliza el dedo sobre la pantalla para moverte y toca para saltar

🎯 Objetivo

  • Recoge monedas (+10 puntos, el combo multiplica)
  • Las gemas valen +50 puntos
  • Los corazones dan una vida extra
  • Pisa el portal verde cuando se abra
  • Caerse al vacío, tocar pinchos o chocar con un obstáculo cuesta una vida
  • Los enemigos normales se pueden aplastar saltando sobre ellos

🏆 Puntuación

  • Moneda: +10 (× combo, hasta ×5)
  • Gema: +50
  • Obstáculo destruido: +15 (× combo)
  • Nivel superado: +500 y bonus de tiempo
  • El récord se guarda en tu navegador
